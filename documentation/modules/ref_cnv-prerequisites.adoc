= {virt} prerequisites

[role="_abstract"]
To migrate between {virt} clusters, verify both clusters have matching {project-short} versions and the source uses {virt} 4.16 or later.

[IMPORTANT]
====
It is strongly recommended to migrate only between clusters with the same version of {virt}, although migration from an earlier version of {virt} to a later one is supported.
====
