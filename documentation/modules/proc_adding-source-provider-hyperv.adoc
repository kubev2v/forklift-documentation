= Adding a Microsoft Hyper-V source provider

[role="_abstract"]
You can add a Microsoft Hyper-V source provider by using the {ocp} web console. The provider connects to the Hyper-V host by using Windows Remote Management (WinRM) and reads VM disk files from a configured Server Message Block (SMB) share.

[NOTE]
====
{project-short} supports only cold migration from Microsoft Hyper-V. Warm migration is not available.
====

.Procedure

. Access the *Create provider* page for Microsoft Hyper-V by doing one of the following:

* *From the Providers page:* In the {ocp} web console, click *Migration for Virtualization > Providers*, click *Create Provider*, select a *Project* from the list, and then click *Microsoft Hyper-V*.

* *From the Overview page (Administrators only):* In the {ocp} web console, click *Migration for Virtualization > Overview*, click *Microsoft Hyper-V* in the *Welcome* pane, and select a *Project* from the list.
+
[NOTE]
====
If the *Welcome* pane is not visible, click *Show the welcome card* in the upper-right corner of the page.
====
+
The default project depends on the active {project-short} project (if *All projects* is active, the default is `+{namespace}+`). Administrators can view all projects; authorized non-administrators see only their assigned projects.

. Enter the provider details:
+
* *Provider resource name*: Name of the source provider
* *URL*: The Hyper-V host address for WinRM connectivity, for example, `192.168.122.115` or `hyperv-host.example.com`
* *SMB share path*: Path to the SMB share that contains the VM disk files, for example, `//192.168.122.115/VMShare`
+
The SMB share must be accessible from both the Hyper-V host and the {ocp-short} cluster.

. Enter the provider credentials:
+
* *Username*: Username for accessing the SMB share. For example, `Administrator` or `DOMAIN\username`
* *Password*: Password for accessing the SMB share

. Choose one of the following options for validating CA certificates:
+
** *Use a custom CA certificate*: Keep *Skip certificate validation* toggled left and provide the certificate:
+
*** *Upload file:* Drag the certificate to the text box, or click *Browse* and click *Select*.
*** *Fetch from URL:* Click *Fetch certificate from URL*, select *I trust the authenticity of this certificate*, and click *Confirm*.

** *Use the system CA certificate*: Keep *Skip certificate validation* toggled left and leave the *CA certificate* text box empty.

** *Skip certificate validation*: Toggle *Skip certificate validation* to the right.

. Click *Create provider* to add and save the provider.
+
The provider appears in the list of providers.
+
[NOTE]
====
It might take a few minutes for the provider to move to the `Ready` status.
====
