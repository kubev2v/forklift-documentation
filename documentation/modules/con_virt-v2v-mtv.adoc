= How MTV uses the virt-v2v tool

[role="_abstract"]
{project-short} uses the `virt-v2v` tool to convert VM disk images to a format compatible with {virt}. The tool automatically enables VirtIO drivers and installs the QEMU guest agent.

`virt-v2v` is included in Red Hat Enterprise Linux (RHEL) versions 7 and later.
