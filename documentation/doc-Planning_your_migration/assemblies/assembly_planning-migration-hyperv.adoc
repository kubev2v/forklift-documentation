= Planning a migration of virtual machines (VMs) from Microsoft Hyper-V

//:context: planning-hyperv

[role="_abstract"]
Create a Microsoft Hyper-V migration plan by setting up network maps, configuring source and destination providers with migration networks, and defining the migration plan in the {project-first} UI.

[IMPORTANT]
====
Importing VMs from Microsoft Hyper-V is a Technology Preview feature only. Technology Preview features are not supported with Red{nbsp}Hat production service level agreements (SLAs) and might not be functionally complete. Red{nbsp}Hat does not recommend using them in production. These features provide early access to upcoming product features, enabling customers to test functionality and provide feedback during the development process.
====
